# Hertzline

Hertzline makes games and the desktop smoother only through changes that are measured, explained, and reversible. It never claims a gain it has not measured on the user's own machine.

## Repositories

| Repository | Role |
|---|---|
| [app](https://github.com/Hertzline/app) | Desktop application and UI |
| [core](https://github.com/Hertzline/core) | Measurement, benchmarks, actions, snapshots, profiles |
| [helper](https://github.com/Hertzline/helper) | Minimal per-OS privileged helpers |
| [packaging](https://github.com/Hertzline/packaging) | Installers, manifests, release scripts |
| [website](https://github.com/Hertzline/website) | Product site and docs (Astro + Starlight) |
| [.github](https://github.com/Hertzline/.github) | Org profile, templates, and shared workflows |

## Principles

- Measure first; report unavailable sensors instead of inventing values
- Every optimization action has apply, restore, and verify
- One-click restore all; restore on crash and uninstall
- No injection, memory reading, or game file modification
- No telemetry by default, ads, or bundled software
- The desktop app never runs fully elevated
